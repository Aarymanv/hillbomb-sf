# src

Game source code (three.js / WebGL 2, ES modules, built with Vite).

| Folder | Contents |
|---|---|
| [`audio/`](audio/) | Audio: engine sound from CC0 recordings, mix bus, city ambience, road and weather sounds, music and radio |
| [`game/`](game/) | Game systems: modes, festival, police, traffic, pedestrians, economy, garage, photo mode, creative mode, tour |
| [`player/`](player/) | Player: input (keyboard and gamepad), chase / hood / in-car cameras, on-foot character |
| [`render/`](render/) | Rendering: physically based sky and atmosphere, post-processing (wet reflections, AO, bloom), weather, lamp lighting, water |
| [`ui/`](ui/) | User interface: HUD, menus, settings, minimap and big map |
| [`vehicle/`](vehicle/) | Vehicles: car physics, handling, tuning, car models and paint |
| [`world/`](world/) | The world: terrain, roads, buildings, landmarks, interiors, props and vegetation |

Per-file descriptions and history: [FILES.md](../FILES.md).
