# public/assets

Game assets: baked map, models, textures, lightmaps, characters, audio (licences in ASSET_LICENSES.md).

| Folder | Contents |
|---|---|
| [`audio/`](audio/) | Audio assets: engine loops, ambience, sound effects, music and UI sounds (CC0) |
| [`baked/`](baked/) | Baked building interior atlases (rooms and shops seen through windows) |
| [`cars/`](cars/) | Car models: player, traffic and parked cars with LODs and baked textures |
| [`hdri/`](hdri/) | Sky HDRIs (CC0), used with ?sky=hdri |
| [`kit/`](kit/) | Building kit: Blender-baked facade pieces (windows, bays, cornices, fire escapes, rooftop units) |
| [`landmarks/`](landmarks/) | Landmark models: exterior LODs, walk-in interiors and baked lightmaps |
| [`map/`](map/) | The baked 1:1 San Francisco map: heights, surfaces, roads, buildings (OpenStreetMap, ODbL) |
| [`peds/`](peds/) | Pedestrian characters (Microsoft Rocketbox, MIT) and animations |
| [`tex/`](tex/) | PBR material textures (ambientCG / Poly Haven, CC0) |
| [`trees/`](trees/) | Tree species: LOD meshes, leaf and bark textures, impostor atlases |

Per-file descriptions and history: [FILES.md](../../FILES.md).
